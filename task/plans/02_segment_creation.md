# 2단계: 세그먼트 생성 (Sliding Window)

## 목표
실시간으로 생성되는 자막 텍스트를 메모리에 버퍼링한 후, 문맥 보존을 위해 30% 중첩(Overlap)을 적용하여 의미 있는 단위(세그먼트)로 잘라 DB에 저장합니다.

## 주요 변경 사항

### 1. 백엔드 (MeetingSession.java)
- 자막 텍스트를 누적 보관하는 `StringBuilder` 버퍼 관리
- **Sliding Window 알고리즘**:
    - 특정 단어 수 또는 침묵(3초 이상) 감지 시 세그먼트 생성
    - 다음 세그먼트 생성 시 현재 세그먼트의 마지막 30% 내용을 포함하여 문맥 유지
- `RealtimeSegment` 엔티티 생성 및 `segments` 테이블 저장

### 2. 트리거 조건
- 긴 문장부호(`.`, `?`, `!`) 감지
- 일정 시간 이상 오디오 데이터 수신 공백 발생 시

## 검증 계획
- 특정 문장 입력 후 DB `segments` 테이블을 조회하여 중첩된 텍스트가 정상적으로 저장되었는지 확인
- 세그먼트 순서(`segment_seq`)가 보장되는지 확인
