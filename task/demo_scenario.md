# 🎥 AI 회의록 시스템 시연 시나리오

이 문서는 프로젝트의 주요 기능을 효과적으로 보여주기 위한 시연 시나리오입니다. 영상 촬영 시 다음 순서에 따라 진행해 주세요.

---

## 🛠️ 시연 준비
1. **서버 실행**:
   - 백엔드 (Port 8080)
   - AI 서버 (Port 8001)
   - 프론트엔드 (Port 3000)
2. **사전 데이터**: '과거 회의'로 검색될 수 있는 데이터를 하나 이상 저장해 둡니다. (예: 대본 A 활용)
3. **업로드용 파일**: `audio_test.mp3` 준비 (루트 디렉토리)

---

## 🎬 시나리오 1: 실시간 회의 및 AI 협업 (Real-time Flow)

### Scene 1: 시스템 접속 및 로그인
- **액션**: 메인 페이지 접속 후 테스트 계정으로 로그인합니다.
- **설명**: "AI 기반 스마트 회의록 시스템에 접속합니다."

### Scene 2: 실시간 회의 시작 및 STT
- **액션**: '실시간 회의록' 메뉴 진입 -> 녹음 시작 버튼 클릭 -> 마이크 권한 허용.
- **대본 내용**: "안녕하세요, 오늘 회의에서는 다음 주 출시 예정인 신규 기능의 마케팅 전략에 대해 논의하겠습니다. 현재 유튜브 광고와 인스타그램 릴스를 활용한 캠페인을 기획 중입니다."
- **관전 포인트**: 실시간으로 텍스트가 변환(STT)되어 화면에 나타나는 모습 강조.

### Scene 3: AI 챗봇 활용 (Global Search)
- **액션**: 우측 챗봇 사이드바 열기 -> 'Global' 토글 활성화 -> 질문 입력.
- **질문**: "우리 프로젝트에서 사용하는 데이터베이스는 뭐야?"
- **설명**: "현재 회의에서는 언급하지 않았지만, 과거 회의 기록을 찾아 답변해주는 'Global Search' 기능을 보여줍니다." (결과: MySQL 9.5 Vector 언급 확인)

### Scene 4: 빠른 요약 및 종료
- **액션**: 녹음 중지 -> **[AI 요약하기]** 버튼 클릭.
- **설명**: "회의가 끝나면 즉시 '빠른 요약' 기능을 통해 핵심 내용을 10초 이내에 파악할 수 있습니다."
- **마무리**: **[저장하기]** 버튼 클릭 (정밀 분석으로 전환).

---

## 🎬 시나리오 2: 파일 업로드 및 상세 분석 (File Flow)

### Scene 5: 음성 파일 업로드
- **액션**: '파일 업로드' 메뉴 진입 -> `audio_test.mp3` 드래그 앤 드롭 또는 선택 -> 업로드 버튼 클릭.
- **참고**: `audio_test.mp3`가 짧기 때문에 업로드 및 분석 시작 과정 위주로 보여줍니다.
- **설명**: "기존에 녹음된 파일도 간편하게 업로드하여 분석할 수 있습니다."

### Scene 6: 회의 분석 현황 확인
- **액션**: '회의 히스토리' 메뉴 진입.
- **설명**: "방금 저장하거나 업로드한 회의가 '분석 중(ANALYZING)' 상태에서 '완료(COMPLETED)'로 바뀌는 과정을 보여줍니다."

---

## 🎬 시나리오 3: 히스토리 관리 및 검색 (Management Flow)

### Scene 7: 상세 회의록 검토
- **액션**: 목록에서 완료된 회의 클릭 -> 전체 대화록(화자 구분), 상세 요약본 확인.
- **설명**: "완성된 회의록에서는 화자별 대화 내용과 시스템이 정리한 상세 요약 결과를 확인할 수 있습니다."

### Scene 8: 관리 및 삭제
- **액션**: 검색창에서 키워드 검색 -> 불필요한 회의 삭제 -> 삭제 완료 확인.
- **설명**: "수많은 회의록 중 필요한 정보를 빠르게 찾고 효율적으로 관리할 수 있습니다."

---

## 💡 촬영 팁
- **자막**: 영상 편집 시 각 Scene별 주요 기능 명칭(실시간 STT, Global RAG, Diarization 등)을 자막으로 넣어주면 좋습니다.
- **배속**: AI 요약이나 정밀 분석 시 로딩 시간이 길어지면 해당 부분은 약간 배속 처리를 하거나 편집으로 넘겨주세요.
- **오디오 파일**: `audio_test.mp3`가 시연에 너무 짧다고 느껴지시면, 1~2분 정도의 실제 대화 녹음본을 추가로 준비하시는 것을 권장합니다.
